## Installation (TL;DR)

1. **Clone / download** the plugin into your project’s `Plugins/` folder.  
2. Re-open the Unreal project; the module will compile automatically.  
3. Open **Edit → Plugins** and ensure “Dialogue Plugin” is enabled.  
4. Restart the editor if prompted.
